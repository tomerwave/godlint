# godlint-core

Analysis and rule engine behind [Godlint](https://github.com/tomerwave/godlint). Published because
`godlint-cli` depends on it.

**The API is not stable.** Nothing here is covered by a compatibility promise before `1.0`, and a
`0.x` release may change it. If you want to run Godlint, install `godlint-cli` instead.
